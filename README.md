# 幕流 MuFlow

从小说或剧本到短剧素材的智能体制作工作流，适用于能够读取本地文件、运行 Python 并调用用户指定 API 的环境。当前源码版本为 **V2.4.1**，采用 [MIT 许可证](LICENSE)。

## 工作流程

1. 开始时先在作品目录建立资产参考图总览、全剧跑前预览和已出成片预览三个入口，再盘点原稿与参考图，确认未明确的视频比例、画风和审核方式。
2. 剧本每批处理5集并接续到全剧完成；再按批完成分镜和资产拆解，保留连续性与自检记录。
3. 分镜依据剧情选择说话人、听话人反应或道具镜头；每组请求为30秒，集数时长按剧情估算。默认按每秒5个实际发声字计算，逐集无对白剧情初估为发声时长的10%—15%，不删必要动作或靠空镜凑秒。
4. 文字、分镜、资产表及提示词交付确认后，使用者再配对自己的图片API并明确允许生图；图片初始并发目标10，可按需调整。人物派生图实际使用母图编辑。
5. 按人工、智能体或联合模式验收资产，逐镜核对剧本场次、主场景素材、内外和日夜；实际查看图片与传图核验分别留证。完整跑前预览交付后，等待使用者明确启动视频。

视频对已授权且就绪的范围不设应用层固定并发上限；服务端额度与限流仍然有效。未知请求状态先核对，不盲目重复提交。所有预览展示真实准备及缺项状态。

- [muflow/SKILL.md](muflow/SKILL.md)：技能入口。
- [使用说明](muflow/00_开始测试.md)：安装后开始测试。

将 muflow 文件夹安装到支持 SKILL.md 的智能体技能目录，具体安装方法取决于客户端。API 地址、模型、价格、账号及 OSS 由使用者在生成配置阶段自行提供，配置与凭据保存在技能之外。

## 验证与限制

V2.4.1 实际通过319项主测试和11项原有离线测试。测试使用合成数据、本地文件和模拟接口，没有调用真实图片或视频生成服务；真实 WorkBuddy 执行、上游接口及成片效果仍需实际验证。

场景程序校验核对登记信息，不等于实际看图或审片。旧项目没有场次基准时需补充核对并复审。原有全剧预览及用户启动门槛保留；执行器当前按集选择，不能自动跳过同一集中的单个错误组。文件打开后，本地浏览器可能需要手动刷新。
