# 验收规则：用可核对的证据决定下一步

没有“感觉差不多就通过”。每条检查看对象版本、依据、实际执行证据及结果。下表程序项可确定性拦截，语义/看图项由智能体实际复核；不能用脚本结构通过替代。

| 阶段 | 通过需要的证据 | 不通过或待复核时 |
|---|---|---|
| 新项目设置 | 读完输入、已有身份图登记，视频比例/画风/范围有用户来源，固定30秒与剧情决定集长直接执行，资产16:9单独列明 | 未确认先询问，不生成媒体 |
| 文字审阅 | 剧本、资产表、分镜及两类提示词、自检完整交付，用户明确确认当前版本 | 不提前出图，不以小样代替 |
| 所选资产验收 | 标准图册真实可见；manual需实际用户采用，agent需真实逐图审查，joint两方分别满足，均绑定当前内容 | 未选环节不适用；用户退回不被AI覆盖，不伪造人工采用 |
| 输入/适配 | 全文可读、源句定位；短剧冲突/因果、时间跨度、OS、入场与信息表达已审查 | 形成具体改编方案，继续不依赖该歧义的工作 |
| 剧本 | 集号/场号/起止/集尾落点完整；每句原文、主体、对象、声道、语气已回对；所有地点时间变化标转场 | 修本段及受影响映射，不为凑秒删词/加速 |
| 分镜 | 实际动作与意图相符；坐站/手持/孩子/车/门/伤衣及跨组末帧连续；机位主体正确 | 补最少动作、调整镜边界或编辑错误图；不编新剧情解围 |
| 时长 | 每组/真实请求30秒、每集无统一时长；逐镜合计准确，去标点对白+动作+停顿+转场−有证据重叠不超镜/组容量；余量有剧情依据，逐集结果展示 | 自动重排完整单元或增组；禁止硬凑集长、加速/删词/无意义空镜；未细排不能仅凭整集平均数通过 |
| 资产表 | 全阶段ID唯一、无漏表/旧集场号；图片任务、Excel、源JSON和提示词一致 | 按精确ID重算溯源并回读导出 |
| 实际图 | 实际查看本版本；人物/服装/阶段/伤衣/数量/空间/背景嵌入物适配 | 错图实际编辑母图；保留退回图、原因及费用 |
| 参考绑定 | 图号、ID、文件哈希、上传对象与API数组顺序同一快照；不越接口上限 | 重组或经授权编辑合适参考，重编索引；不能删图后留旧图号 |
| 现金画面 | 源文露钱/撒钱动作已留证据并替换；执行剧本、分镜、实际图和请求均仅封装道具，不改变金额和关键结果 | 任一阶段出现正向露钱/抛撒画面即不通过；未回源或未看图则待复核 |
| 真正的请求 | 每句及片段进入实际请求词，台词顺序、角色、声道一致；镜头全部覆盖 | 修编译词及后续映射，防止前组只发三句、下组却从第七句开始 |
| 跑前预览 | 独立来源全量/用户明确范围、真实请求/图片/参数/费用与自检已交付，本地/执行视图同内容；之后实际用户明确启动；无临时联网绕路 | “做到预览”不是启动；联调/样片也停留，不借旧项目预授权跳过 |
| 执行 | 每次POST前落稳定ID和快照，原始回执独立留存；请求未知可核对 | 查原任务，明确失败才原参数新尝试；新增改词试片另判权限 |
| 收片 | 原任务成功、文件已保存、长度与Range匹配、MP4声明块未超实际边界 | 续传/刷新同任务地址；不能拿有时长信息当完整文件证明 |
| 报告 | 全部尝试采用情况可见；任务状态一致；费用预留/报告扣费/退款/未知分开 | 未知留未知，不拿估算宣称平台对账完成 |

交付完整性与内容采用分开：脚本可验文件，内容由用户审片反馈。没有真实平台联调记录时不能写平台已通过。用户可看见所有已保留的试片和退回图；智能体认为应退回不是用户已经看过或批准采用。


## V2.3 追加验收

| 对象 | 通过依据 | 不能代替的事项 |
|---|---|---|
| 全剧阶段循环 | 剧本5集批全部完成，再分镜资产5集批全部完成，获准图片20张批接续；真实产物、哈希、覆盖与批次台账对应 | 前一批完成不等于阶段完成，上下文长度不允许截成前几集 |
| 初始化与持续进度 | init_project创建真实双HTML，refresh_progress每批/每次资产事件后更新；资产表实际文件入口持续可达 | 固定入口不是占位路径，未知总量不能写已完成百分比 |
| 来源基准 | 原稿独立集标题或source_sha256绑定的已确认分集规划；原稿/登记/制作/本次范围分别对照 | 项目只登记少量集数不能自证全剧；小说章节数不等于集数 |
| 真实审查 | 当前subject_digest、实际审查者/时间、具体规则/预期/观察/证据；分镜check覆盖具体shot_ids | 结构通过、非空字符串、模板批量通过不能证明真实语义/视觉审查 |
| 自然实际请求 | 真正TXT与冻结请求逐镜可执行，台词回拼、角色声道/图序一致，关键连续性完整，时间无浮点尾巴 | 在HTML隐藏JSON不足；底层JSON数据与JSON协议继续保留 |
| 图册归组去重 | 实体/身份/母图链归组，母图及首次剧情使用排序；同ID同哈希当前只主展示一次，真正旧版折叠 | 不删除请求/失败/原因/账务记录，不用图片副本数推断生成次数 |
| 内容级批准 | 相同资产内容与文件版本的真实采用可复用；改一项只使相应内容及依赖待复核 | 普通刷新不循环索要采用，旧视频启动不自动覆盖新完整快照 |
| 两视图 | 同一内容摘要，本地真实图与缺项可审；执行另查远端对象/同版哈希、引用有效及实际数组 | 可看页面不等于内容通过、传输就绪或用户已启动视频 |

每项实际检查需留执行记录；未运行、未看图、无真实客户端/在线证据时列未执行或待复核。当前版本打包不是安装、发布、生图或视频执行，不新增自动视频内容审查或自动拼接。
