# 三个固定入口与稳定成片播放

输入盘点后调用init_project.py，或已有项目调用refresh_progress.py PROJECT，立即给用户三个真实可点击文件链接：

- 03_资产图/00_资产参考图总览.html：实际图片、审核、采用与历史。
- 07_跑前预览/全剧跑前预览.html：当前全剧准备、参考绑定、实际请求与执行条件。
- 08_视频/已出成片预览.html：已登记任务、已下载文件和播放入口。

尚未制作时如实占位；创建第三个入口不是视频启动授权。资产表完成后另外给实际表格入口。固定页不在后台轮询时重新导出；用户要查进度时读取各自实际记录。

## 成片数据与播放

video_gallery.py PROJECT 从production.sqlite只读获取全部任务（跨批保留），也可用--summary显式指定原runner的batch_summary.json。批量runner保存任务后及退出前自动更新成片清单；没有依赖字典、目录里发现一个MP4或远端success就计入可播放。只有downloaded且本地文件非空、长度与完整性登记存在时进入文件就绪；缺文件/长度变化如实显示待恢复。本检查不解码，不证明台词、表演或影片内容通过。

成片HTML和JS客户端保持稳定，进度写到独立成片进度.js/成片清单.json；没有变化就不写。页面每5秒只取进度数据，增量更新状态和新增卡片；不刷新整页、不替换已有video节点、不对同版重设src/load，也不改变播放位置/暂停状态。按实际集号/组号排列；视频preload=none，点击对应卡片才加载。打开旧版后若有新版，保留旧播放器并让用户点击切换。

只检查文件传输/页面/播放器技术状态，不自动抽帧、听音、转写或评价内容；不自动拼接。播放错误不触发生成API或新收费版本。

## 内置预览器不支持本地媒体时

提供文件入口之外，智能体运行：

~~~text
python scripts/serve_video_preview.py 项目/project.json --background
~~~

把返回的http://127.0.0.1:本机端口/链接直接交给用户（可在本地浏览器打开）。此地址仅本机可用，不是分享网址；无需OSS。服务只提供已登记视频及本播放器资源，支持MP4 Range/HEAD拖动读取，不暴露整个项目目录、配置或回执。后台在Windows隐藏启动；复用同项目既有服务，不为刷新反复起服务。关闭/重启机器后要恢复则重新运行，脚本返回失败时如实报告。

不要在已出成片页每次轮询时调用refresh_progress重写三个HTML，不给video加每秒变化的URL缓存参数。URL缓存参数只用于轻量进度脚本，实际视频路径和哈希保持稳定。播放器提供明确错误及“打开视频文件”；内置查看器不支持的情况不得伪记已验证播放成功。

已有项目需只读排查时可加--out 独立预览目录，把面板和服务状态写在独立位置，仅从原项目读取任务和已下载文件。

当前浏览器技术测试与实际WorkBuddy内置播放器兼容分开记录；真实成片内容仍由用户审阅。
