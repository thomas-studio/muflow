# 首次使用与测试 · V2.3.1

本包供可读本地文件并执行脚本的制作智能体使用。解压保留muflow，桌面交付不自动安装、不改旧生产项目。安装和配对不提交媒体测试。

## 启动与持续入口

完整读原稿、项目要求与已有身份图，确认未明视频比例、画风、范围和asset_review_mode（manual/agent/joint）；已确认的不重复询问。已有身份原图mode=reuse，保留原文件及哈希，阶段派生实际编辑母图。新资产默认16:9，视频比例独立确认。

输入盘点后运行init_project.py 项目目录 原稿文件初始化，自动建立三入口；续接或每批事件后运行refresh_progress.py 项目/project.json。也可分别运行asset_gallery.py建立03_资产图/00_资产参考图总览.html，运行build_preview.py建立07_跑前预览/全剧跑前预览.html。缺API/缺图/未确认时也建立真实页面并列准备中与缺项，不上传、不生成。实际创建后将真实文件链接交用户。资产表生成后提供实际文件入口；三处持续刷新，不让用户到临时目录寻找产物。

剧本每批5集接续到全剧完成，再分镜资产每批5集接续到全剧完成；纯文字剧本、资产表、正式分镜、两类提示词和自检交付确认后，获准图片每批20张续做到全量资产完成。单批不是阶段完成；上下文续接读台账，不能停在前几集或擅自缩全剧范围。只有用户明确限定部分集数，才另列本次范围，同时保留原稿全量覆盖。

每组真实视频请求固定30秒，各集按剧情估算得到组数和时长，不询问统一单集时长。默认4.5字/秒、每动作拍2.2秒是估算，见[timing.md](timing.md)。图片按已选模式验收；固定跑前页本地/OSS执行核对共用同一内容，完整交付之后仍等用户明确启动视频。

## 配对

全剧文字工作全部完成并交付后才询问API/OSS，启动不催配置。将“提供／完成API配置后允许开始本批资产生图”合并说明并取得实际许可，随意收到API资料不自动试生。此时首次集中核对使用者提供的真实协议、上游、模型、图片编辑、计价/上限、尺寸/时长/图数/并发、鉴权及传图方式。已有用户允许复用的有效本机配对可复用，作品比例、画风、身份及范围不跨作品继承。

本包仅有未配对profile模板，无可用API、固定上游、具体模型、价格或OSS账号。配置存技能之外，密钥只用环境变量或客户端凭证引用。setup_profile.py --input 使用者接入资料.json --out 使用者本机配置/profile.json只做本机核对，不调用外部API；verification_evidence来自真实协议或此前已获准证据。配对不是阶段批准，也不需要技能修改核验。

无API继续文字与本地预览，不调用平台原生/默认/其它账号通道。OSS仅是用户选定传输方式，选用才核对私有对象、引用有效期和哈希；本地审阅不依赖OSS，真实视频执行仍检查所需远端条件。不得为了联调提交空白样片或短时长探针。

## 迁移与测试

先在获准副本登记独立原稿集标题或绑定原稿哈希的已确认分集基准，补workflow、deliverables、input_assets、验收模式与实际审查。普通图册/预览刷新复用相同内容的真实批准；改图改词只影响对应内容及依赖。源文、旧稿、合格图片、退回版本和回执保留，不因升级重生全部资产。

运行本版tests目录的离线行为测试，实际结果查看validation。已有基础回归包含run_offline_tests.py、test_v2.py、test_staged_review.py、test_timing.py、test_delivery_controls.py；可读请求另有test_readable_prompts.py，其它新增测试按本版实际文件执行。测试采用原创／合成数据，不调用收费媒体服务，不以测试数量证明作品效果或真实客户端工具选择。

Python3.10+；表格openpyxl，图像核验Pillow，选择OSS才需oss2。Word按当前文档工具能力导出与渲染，不支持就记录未执行。公开包不附原小说、私人图片/路径、真实配对、凭证或用户批准材料，不新增自动视频内容审查或自动拼接。

完整操作见[分阶段执行](staged-review.md)、[资产验收与图册](asset-delivery.md)、[审批来源](review-controls.md)和[验收规则](acceptance.md)。内容检查通过与用户最终审片采用分开；未做在线协议/扣费/模型效果或真实客户端测试，均不得写已通过。


joint已明确就先由智能体实际审图并汇总问题，等待用户反馈后按授权修图，再由所需双方复核。不得在人工未答复时填通过。“残血/半血/满血”可辅助显示，但必须和真实内容/审核/技术状态对应，未齐不能满血，满血仍不授权视频。
